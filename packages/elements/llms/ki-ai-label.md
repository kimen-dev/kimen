# ki-ai-label

> A compact provenance mark for AI-generated content, with optional details and a user-initiated request to restore their original text.

## When to use

Mark text or a value generated by AI. Include the source in
`explanation` when people can inspect how it was generated. In a `ki-input`,
place the label in the `end` slot to describe the field's provenance.

## When not to use

Use a status component for active generation or processing,
and an application action for changes that do not restore the person's text.

## Examples

# AI label examples

Mark generated content beside the text it describes.

```html
<header>Weekly summary <ki-ai-label></ki-ai-label></header>
```

Give people a short provenance explanation when they need to assess a result.
The model and generation time are optional.

```html
<ki-ai-label
  explanation="Written from the incident reports of the last 30 days."
  model="Standard"
  generated-at="2026-11-19T10:32"
></ki-ai-label>
```

Use the input's `end` slot to announce the provenance with the field
description. Keep the original in application state and restore it on
`ki-revert`.

```html
<ki-input id="subject" label="Subject" value="Incident summary">
  <ki-ai-label
    slot="end"
    explanation="Suggested from the incident reports."
    revertible
  ></ki-ai-label>
</ki-input>

<script type="module">
  const field = document.querySelector('#subject');
  const label = field.querySelector('ki-ai-label');
  const original = 'Weekly summary';

  label.addEventListener('ki-revert', () => {
    field.value = original;
    label.remove();
    field.focus();
  });
</script>
```

## Token stylesheets

- `@kimen/tokens/css/core` once per page and `@kimen/tokens/css/ki-ai-label`: the default, only the tokens ki-ai-label needs, including those of the components it renders. Load the sheet of every ki-* tag the page uses.
- `@kimen/tokens/css`: every token, once per page, instead of the core and the tag sheets. The simple alternative.

## Attributes

- `explanation` (string | undefined): Plain-text explanation of how the content was generated. Supply a nonblank explanation to offer disclosure. Omit it for a static mark.
- `generated-at` (string | undefined): Optional generation date or time, displayed as supplied.
- `generated-at-label` (string, default 'Generated'): Visible prefix for the generation date or time.
- `label` (string, default 'AI'): Short visible provenance text. Localize it with the trigger name.
- `model` (string | undefined): Optional plain-text model name shown in the explanation.
- `model-label` (string, default 'Model:'): Visible prefix for the model name.
- `popover-label` (string, default 'About this content'): Accessible name of the non-modal explanation panel.
- `revert-label` (string, default 'Revert to my text'): Visible text and accessible name of the revert action.
- `revertible` (boolean, default false): Offer the revert action inside the explanation. Enable it when the application has the original text and handles `ki-revert`.
- `size` ("md" | "sm", default 'sm'): Size of the painted mark. Unknown values use the small metrics.
- `trigger-label` (string, default 'AI-generated: about this content'): Accessible name of the disclosure button. Include the visible label.

## Slots

None.

## Parts

- `explanation`: Source explanation paragraph.
- `icon`: Decorative sparkles glyph.
- `label`: Tinted mark containing the icon and visible text.
- `metadata`: Optional model and generation time.
- `popover`: Non-modal explanation panel.
- `revert`: Button that requests reversion.
- `trigger`: Disclosure button, available with an explanation.

## Events

- `ki-revert` (CustomEvent<void>): Bubbles when a person requests their original text. Use this request to restore the original from application state.

## Methods

None.
