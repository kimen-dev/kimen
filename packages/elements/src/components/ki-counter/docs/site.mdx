Use a counter for unread or pending items on a trigger, or for presence on
an avatar. Use `ki-badge` for object status and text or `ki-badge` for a count
within a list row.

A count of zero hides the pill. Values above `max` display the cap with a
plus sign. Set `dot` for a marker without digits. The tone defaults to
`danger` and also accepts `primary`, `success`, and `neutral`.

## Accessible placement

Use the `counter` slot on `ki-icon-button` or `ki-avatar`. For an external
trigger such as a link, set `for` to its ID in the same document or shadow root.

```html
<a id="inbox-link" href="/inbox" aria-label="Inbox, 120 unread">Inbox</a>
<ki-counter for="inbox-link" value="120"></ki-counter>
<p id="inbox-updates" role="status"></p>
```

Include the meaning in the trigger's accessible name. For important changes,
update a pre-existing polite status region once with the localized message.
