Place each `ki-suggestion` directly inside a suggestions group. Put the prompt
as plain text in the default slot. The visible title supplies the button's
accessible name and the prompt text emitted by the group.

<Demo layout="block" code={`<ki-suggestions label="Start a conversation" variant="cards">
  <ki-suggestion description="For the merged pull requests">Draft release notes</ki-suggestion>
  <ki-suggestion>Plan the next release</ki-suggestion>
</ki-suggestions>`} />

Use `description` for optional context, such as the source material or the
scope of the prompt. Cards render it under the title. When supplied, it gives
assistive technology separate context in either variant.
