## Handle a decision

Listen for `ki-approve` or `ki-deny` on the request. Approval reports a
boolean `remember` preference. The host can honor that preference for the
requested action in the current conversation. Route each choice to a declared
surface action through trusted host code. Use `tone="danger"` for destructive
approval.

Set `state` to `approved`, `denied` or `expired` after recording the outcome.
Use `resolved-by` and `resolved-at` for the name and time in the summary.

## Focus and announcements

The group is named by its question and announces new requests politely. Call
`focusPrompt()` when the person is waiting for the assistant. An active
editor retains focus. Tab reaches refusal before approval, and Escape leaves
the decision pending.
