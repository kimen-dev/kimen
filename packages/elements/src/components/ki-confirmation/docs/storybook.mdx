Use the default slot for the facts the person needs to decide. Describe any
lasting effect in `consequence`, and set `tone="danger"` when approval is
destructive.

## Customization

Use `--ki-confirmation-bg` and `--ki-confirmation-fg` for the surface and
text. Use `--ki-confirmation-border`, `--ki-confirmation-radius` and
`--ki-confirmation-padding` for its frame. The optional
`--ki-confirmation-bg-image` and `--ki-confirmation-backdrop-filter`
default to `none`.
