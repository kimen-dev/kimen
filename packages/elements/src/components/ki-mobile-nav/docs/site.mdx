Use MobileNav for the main destinations of a phone layout. Use buttons for actions.
Switch to the app's TopNav or Sidebar at the same breakpoint you use for the
wider layout. For more than five destinations, use a navigation pattern with
room for the full set.

## App shell

Place one bar after the content in the app shell. Its host reserves the bar's
height and bottom inset so the last content can scroll clear. The default
`fixed` variant spans the bottom edge. Set `variant="floating"` for an inset
raised bar. Both variants account for the bottom safe area. Use
`viewport-fit=cover` in the page's viewport metadata when drawing edge to edge.

Register the icons used by each destination.

```js
import '@kimen/elements/icons/house';
import '@kimen/elements/icons/search';
import '@kimen/elements/icons/inbox';
```

## Accessibility

Use a unique landmark label when several navigation landmarks appear on the
page. Keep each destination's text short and visible, and update `current` as
the route changes. Each item is a native link in the Tab order. When the browser
reports or exposes the software keyboard through viewport geometry, the bar
temporarily hides.
