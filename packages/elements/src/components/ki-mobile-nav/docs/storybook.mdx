# ki-mobile-nav

Place three to five labeled destinations after the main content. The host
reserves their space in the page flow. Use the same breakpoint to switch the
mobile and desktop navigation.

<Canvas of={MobileNavStories.Floating} />

Tab and Shift+Tab move through destinations. Enter follows the focused link.
Set `current` on the item matching the active route.
