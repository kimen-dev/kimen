Use a tree item inside [Tree](../tree/) or another tree item. A row contains
its text label and any nested child items. Set `expanded` to start with its
children visible. A disabled row remains reachable with the arrow keys.

Import the glyph module before using its name in `icon-name`. The label
text names the row and the icon is decorative.

```js
import '@kimen/elements/icons/file-code';
```
