Use one disclosure per tool call. Supply a stable tool ID in `name` and an
optional human-readable `title` (`toolTitle` in typed bindings). A completed
call shows its elapsed duration when supplied in milliseconds.

Put arguments in `input`, results in `output` and failure details in
`error`. Use CodeBlock for structured text. A failed call opens by default.
Set `open="false"` to start it collapsed. The native summary responds to
pointer activation, Enter and Space.

Set `retryable` to offer the Retry button on a failure. Handle the
`ki-tool-retry` event in your app or bind a declared action to the ToolCall in
a guarded surface. For approvals, show the `approval` status and provide a
separate confirmation control.

Listen for `ki-tool-status-change` and append one entry to your conversation's
existing log. The event provides `detail.name`, `detail.status` and
`detail.label`. Initial states remain available in the summary. Localize the
badge and caption labels through their label props. Set `locale` to format
the completed duration for your audience.
