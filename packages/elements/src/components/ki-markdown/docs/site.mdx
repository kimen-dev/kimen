## Provide source

Set `src-text` for a string supplied as an attribute. In JavaScript, assign
`srcText` or update the element's direct text nodes. An explicit `srcText`
value takes precedence, including an empty string. Escape angle brackets when
writing source into an HTML document so the browser passes them as text.

Set `streaming` while appending chunks to the source and clear it when the
answer ends. An open code fence stays a code block as lines arrive. A table
appears when its delimiter is complete and its last row can fill in over time.

## Formatting and destinations

The supported Markdown subset includes headings, paragraphs, emphasis,
strikethrough, inline and fenced code, links, opt-in images, ordered and
unordered lists, task items, blockquotes, tables and hard breaks.
Task checkboxes show their state and stay disabled. Fenced code uses
[CodeBlock](/docs/components/code-block/) and its language label. Tables have
native column headings. A blockquote that starts with `[!NOTE]` uses
[Note](/docs/components/note/).

The default heading offset of 2 renders a top-level Markdown heading as
`h3`. Set `heading-offset` from 0 to 5 to fit the surrounding page outline.
The deepest rendered level is `h6`.

HTML in the source is shown as text. Links and enabled images accept HTTP,
HTTPS and relative references. A guarded surface can restrict both to its
configured absolute origins. Rejected destinations leave the matching text
visible. Set `allow-images` to let images load. Cross-origin links use
[Link](/docs/components/link/) and include its new-tab announcement.

## Register child elements

The package loader registers Markdown, Link, CodeBlock and Note. With direct
imports or a framework wrapper, register the child elements your content uses
before rendering Markdown.

```js
import { defineCustomElement as defineCodeBlock } from '@kimen/elements/ki-code-block';
import { defineCustomElement as defineLink } from '@kimen/elements/ki-link';
import { defineCustomElement as defineNote } from '@kimen/elements/ki-note';
import { defineCustomElement as defineMarkdown } from '@kimen/elements/ki-markdown';

defineCodeBlock();
defineLink();
defineNote();
defineMarkdown();
```

With a framework wrapper, use the first three registrations. The wrapper
registers Markdown.
