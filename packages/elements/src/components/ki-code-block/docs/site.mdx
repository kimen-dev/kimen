Supply the snippet as a plain text child. Escape HTML markup in static
examples or assign `textContent` when you create the element in JavaScript.
JavaScript, TypeScript, JSON and Gherkin have syntax colors. Other language
labels display the source as plain text. Markup inside the snippet is never
rendered, so highlighting written as HTML shows as literal text.

Set `language="gherkin"`, or `feature`, for Gherkin contracts. Keywords from
Gherkin's English and Spanish dictionaries are colored when they open a line,
so `Y` or `E` inside a sentence stays plain. Comments such as
`# language: es`, tags, quoted text, doc strings, table pipes and cells, and
outline placeholders such as `<count>` are colored too.

Use `line-numbers` to show a gutter and `highlight="3,5-7"` for one-based
lines or inclusive ranges. Long lines scroll by default. Add `wrap` to wrap
them. The scroll area is a Tab stop, and the arrow keys scroll overflowing
code. The language and filename name the figure and scroll area. The scroll
area describes highlighted lines, and line numbers are hidden from assistive
technology.

CopyButton copies the original whitespace and reports the outcome. Set
`copyable="false"` to hide the button. Localize the figure's fallback name
with `label`, the description prefix with `highlight-label` and the copy
control with `copy-label`, `copied-label` and `copy-error-label`.

Listen for `ki-copy` to receive the original source in `detail.value`, or
`ki-copy-error` to respond to a failed write. A guarded surface can bind a
declared action to `ki-copy`.
