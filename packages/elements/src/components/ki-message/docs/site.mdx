Use a message for each chronological entry in a [ki-conversation](../conversation/).
The `user` role aligns a bubble at the inline end. The default `assistant`
role shows a reply with an avatar at the inline start. An `event` is a
centered note with an optional decorative `icon-name`.

## Compose the message

Use the default slot for text or formatted content. Give an assistant reply
a custom `avatar` when it has its own identity. Supply controls such as
links or buttons in `actions` and handle them in your application. See
[Message actions](../conversation/#message-actions) for the reply toolbar,
ratings, regeneration and the branch picker. Import any
additional event glyphs the same way you would for [ki-icon](../icon/).

## Accessible names and streaming

`author` sets the article's complete accessible name. The role defaults
are “You said,” “Assistant said” and “System event.” Supply a localized
author string such as “Ava dijo” for a Spanish transcript. The visible
message content is separate from the name.

Set `streaming` while appending chunks to the content. The caret stays
visible and still with reduced motion. Clear `streaming` when the response
is complete so the polite conversation log can present it as one update.
