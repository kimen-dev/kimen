title: ki-fab-menu-item
description: A command or native link inside a floating action menu.
---

import CemApi from '../../../../../../site/docs/src/components/CemApi.astro';

Place this element directly inside a `ki-fab-menu`. Use its default slot
for a short, visible action label and `icon-name` for a decorative glyph.
Provide `href` for native navigation or handle the menu's `ki-select`
event for commands. Set `value` when a command needs a stable identifier
across translations.
