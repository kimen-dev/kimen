# ki-stepper

Give the list an accessible name using `label`. Arrange direct `ki-step`
children in task order. The horizontal layout becomes a disclosure below
22rem. Select `vertical` to keep the steps stacked and open at every width.

The disclosure retains access to the same completed links and descriptions.
Override `summary-label` and `count-label` to translate its text. Override
`done-label`, `current-label`, `upcoming-label` and `error-label` to translate
the state text for assistive technology.
