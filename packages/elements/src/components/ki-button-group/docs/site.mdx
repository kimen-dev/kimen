Group related actions such as Undo and Redo or text formatting. Use a
segmented control for a single-choice setting and links for navigation.

## Spaced and attached groups

Give the group a label that describes the actions together. Add `attached`
to join the buttons at their inner edges. An attached group takes the first
button's variant and size. Set `size` on the group to give every button that
size in any mode.

<Demo
  code={`<ki-button-group label="History">
  <ki-button type="button">Undo</ki-button>
  <ki-button type="button">Redo</ki-button>
</ki-button-group>
<ki-button-group label="Clipboard" attached>
  <ki-button type="button">Copy</ki-button>
  <ki-button type="button">Paste</ki-button>
</ki-button-group>`}
/>

Use `type="button"` for actions inside a form that should leave the form alone.

## Keyboard toolbar

Tab enters the toolbar at its first available action, then returns to the most
recently focused action on later visits. Left and right arrows follow the
visual order in both writing directions. Home and End reach the first and last
available actions. Tab and Shift+Tab leave the toolbar.

Wrap each icon button in a tooltip with the same label. Keep that label stable
on toggles and update `pressed` with the application state. The button exposes it as `aria-pressed`. A vertical
separator can distinguish sets of actions within the toolbar.

```js
import '@kimen/elements/icons/bold';
import '@kimen/elements/icons/italic';
```

<Demo
  live={false}
  code={`<ki-button-group label="Formatting" toolbar size="sm">
  <ki-tooltip label="Bold">
    <ki-icon-button label="Bold" variant="ghost" pressed="true">
      <ki-icon name="bold"></ki-icon>
    </ki-icon-button>
  </ki-tooltip>
  <ki-tooltip label="Italic">
    <ki-icon-button label="Italic" variant="ghost" pressed="false">
      <ki-icon name="italic"></ki-icon>
    </ki-icon-button>
  </ki-tooltip>
  <span role="separator" aria-orientation="vertical"></span>
  <ki-button type="button" variant="ghost">Clear formatting</ki-button>
</ki-button-group>`}
/>

## Split button

Use an attached text button for the primary action and a labeled chevron
button to open the alternatives. When `ki-menu` is available in your build,
set its `anchor` to the chevron button's ID. The application handles the
primary click and the menu selection independently. Set the icon button’s
`expanded` property to the popup’s current open state.

## Theme overrides

`--ki-button-group-gap` controls spacing between ordinary buttons.
`--ki-button-group-divider` controls the ink of vertical toolbar separators.
Use a surrounding `data-ki-density="touch"` region when the layout needs
larger targets.
