# Link examples

## Running text

Keep the underline inside a sentence. The link inherits font size and weight.
The external marker accompanies links that open in a new tab.

<Canvas of={LinkStories.RunningText} />

## Standalone navigation

A navigation row can identify links through placement. Here the underline
appears on hover and keyboard focus, and stays visible without hover.

<Canvas of={LinkStories.Standalone} />

## Trailing icon

The `end` slot places a decorative icon after the text using the link's
icon size and gap. This example also sets a heavier weight and custom
neutral hover ink.
