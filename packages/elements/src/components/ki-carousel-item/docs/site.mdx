---
title: ki-carousel-item
description: Provide one slide and optional decorative preview media to a carousel.
---

import CemApi from '../../../../../../site/docs/src/components/CemApi.astro';
import Demo from '../../../../../../site/docs/src/components/Demo.astro';

Use one item per slide. Put text, links and controls in the default slot.
For layouts with previews, add decorative media to the `preview` slot.
The parent carousel assigns the item's position name and manages whether
its content is available.

  <ki-carousel-item>Choose a theme</ki-carousel-item>
</ki-carousel>`} />
