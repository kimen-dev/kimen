Supply a group `label` and place each `ki-suggestion` directly inside it.
Write the prompt as plain text. That title is also the button's accessible
name. A supplied description gives assistive technology separate context.
Tab moves through the buttons in reading order. Enter or Space chooses the
focused suggestion.

## Connect a composer

The group dispatches a bubbling, composed and cancelable `ki-select`. Read
`event.detail.text` to get the chosen prompt. In the default `send` mode, the
application's event handler sends the prompt. Set `mode="fill"` to populate
the composer's draft for editing.

Assign `composer` in JavaScript. It accepts a writable string `value` and a
`focus()` method. Both modes focus the composer after dispatch. Fill mode
also replaces its draft. Cancel the event with `preventDefault()` when your
handler takes over value or focus.

Add a draft field after the starter group in the first example.

<Demo code={`<label for="draft">Message</label>
<textarea id="draft"></textarea>`} live={false} />

<Demo code={`const suggestions = document.querySelector('#starters');
suggestions.composer = document.querySelector('#draft');`} lang="js" live={false} />

Register both tags when using direct imports or framework wrappers.
