# Keyboard and localization

The named disclosure opens with Enter or Space. Its explanation receives
focus. Tab reaches the optional revert action and can leave the panel. Escape
closes the panel and returns focus to the disclosure button.

Translate the mark with `label` and set a corresponding `trigger-label`
that contains the visible label. Set `popover-label` and `revert-label`
to translate those controls, and use `model-label` and `generated-at-label`
for the metadata. The containing `ki-input` can translate “Suggested by AI”
with `ai-suggestion-text`.
