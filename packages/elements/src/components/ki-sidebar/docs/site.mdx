## Use the rail

The toggle keeps focus when the layout changes. Links keep their accessible
names and navigation behavior in the rail, and show their names in tooltips
on hover and keyboard focus. A counted item shows a pill in the panel and a
dot in the rail. Localize its accessible name using `count-label`.

Set `preference.storageKey` to a stable key per profile to remember a visitor's
mode in this browser. The `ki-sidebar-change` event also reports
`detail.collapsed` for application-owned persistence. Give each sidebar a
distinct landmark label when several share a page.

## Compose account access

The `footer` slot accepts your account trigger. Connect it to the
application's menu and give it a name that works at rail width. Keep the
trigger available in both modes. The `brand` slot is for expanded
presentational branding.
