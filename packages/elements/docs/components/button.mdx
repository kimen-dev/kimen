# ki-button

A token-styled action button with native button semantics.

**When to use** — trigger the single main action of a view, supporting
actions in descending hierarchy, or confirming/destructive actions through
tone. Use `toggle` for an action that stays pressed between activations, and
`href` for a call to action that navigates.

**When NOT to use** — links in running text (use `ki-link`), icon-only
actions or progress of a page or region.

## Examples

Use `primary` for the single main action. It has a filled background.
Use the outlined `secondary` for supporting actions. It is the default.
Use `quaternary` for neutral text actions and `ghost` for accent text actions.
Use `outline` for an outline at rest and a filled selected state in toggle mode.

```html
<ki-button variant="primary">Save changes</ki-button>
<ki-button>Cancel</ki-button>
<ki-button variant="quaternary">Skip</ki-button>
<ki-button variant="ghost">Learn more</ki-button>
<ki-button variant="outline">Print</ki-button>
```

`tertiary` is deprecated. Use `secondary` for new buttons. Existing
`tertiary` buttons share the `secondary` appearance in onmars and keep
their legacy appearance in Material 3. Development builds warn when
the deprecated variant is used.

In the momentary primary, secondary, quaternary and ghost variants, `tone`
carries semantic intent such as success or danger. The default is `neutral`.

```html
<ki-button variant="primary" tone="success">Confirm order</ki-button>
<ki-button variant="secondary" tone="danger">Delete draft</ki-button>
```

Sizes (`xs` to `xl`, default `md`) and the `start`/`end` icon slots — the
default slot stays the label because it is the accessible name source:

```html
<ki-button size="sm">Compact</ki-button>
<ki-button size="xl" variant="primary">Get started</ki-button>
<ki-button>
  <span slot="start" aria-hidden="true">↓</span>
  Download
</ki-button>
```

## Toggle mode

Set `toggle` to keep the button pressed until the next activation. Set
`selected` to choose its starting state. The pressed state is announced
under the same button label. Pointer, Space and Enter activation emit one
`ki-change` with `{ selected }`. Programmatic `selected` updates are silent.
Toggle colours follow the variant and selection state.

## Link mode

Set `href` for a call to action that navigates, such as "Get started". The
button renders a native link with the same `button` part, so every variant,
size, token and `::part(button)` rule styles it like the button. Enter
follows it and Space does not, as on any link. `target`, `rel` and
`download` pass to the link; `target="_blank"` without `rel` gets
`rel="noreferrer noopener"`.

A link never submits or resets a form: `type`, `name`, `value`, `toggle`
and dialog commands do nothing while `href` is set. A disabled link drops
its destination, leaves the Tab order like a disabled button and is exposed
as an unavailable link. A blank `href` keeps the native button.

<Canvas of={ButtonStories.Link} />

```html
<ki-button variant="primary" href="/start">Get started</ki-button>
```

## Recipe: buttons in a form

In momentary mode, `type` defaults to `submit`. To cancel a submission, call
`preventDefault()` on the form's `submit` event.

```html
<form id="profile">
  <ki-input name="name" label="Display name" required></ki-input>
  <ki-button type="submit" variant="primary" name="intent" value="save">Save</ki-button>
  <ki-button type="reset">Reset</ki-button>
</form>

<script type="module">
  document.getElementById('profile').addEventListener('submit', (event) => {
    event.preventDefault(); // cancel here, not on the button's click event
    console.log(Object.fromEntries(new FormData(event.target)));
  });
</script>
```

Use `type="button"` for an independent momentary action. Toggle mode takes
precedence over `type` and acts independently of form submission and reset.

## Recipe: open a dialog

Use `commandfor` with the ID of a `ki-dialog` in the same document or shadow
root. The dialog command takes precedence over form submission or reset.

```html
<ki-button commandfor="draft-preview" command="show-modal">Preview draft</ki-button>
<ki-dialog id="draft-preview" heading="Draft preview">
  This draft is visible only to you.
  <ki-button slot="footer" commandfor="draft-preview" command="close">Done</ki-button>
</ki-dialog>
```

## Recipe: a start-aligned choice

`--ki-button-justify-content` places the content along the button and
`--ki-button-text-align` aligns the lines of a multi-line label. Both are
`center` by default. Set both to `start` for a start-aligned choice.
`--ki-button-inline-size` defaults to `fit-content`. Use `100%` to fill
the containing block in button or link mode.

<Canvas of={ButtonStories.StartAligned} />

```html
<style>
  .choice {
    --ki-button-inline-size: 100%;
    --ki-button-justify-content: start;
    --ki-button-text-align: start;
  }
</style>
<ki-button class="choice" variant="outline" toggle>
  <strong>Starter</strong><br />One agent, one repository
</ki-button>
```

## Customization

| Token                                   | Controls                              |
| --------------------------------------- | ------------------------------------- |
| `--ki-button-primary-neutral-rest-bg`   | Primary variant resting background    |
| `--ki-button-md-height`                 | Height of the `md` size (per-size)    |
| `--ki-button-md-radius`                 | Corner radius of the `md` size        |
| `--ki-button-inline-size` | Host and control inline size (`fit-content`) |
| `--ki-button-md-icon-size` | Slot box and ki-icon glyph size at `md` |
| `--ki-button-outline-hover-{bg,fg,border}` | Hover palette for outline actions and unselected outline toggles |
| `--ki-button-outline-selected-border` | Selected outline edge |
| `--ki-button-toggle-unselected-hover-overlay` | Hover wash for unselected filled and quiet toggles |
| `--ki-button-font-weight`               | Label font weight                     |
| `--ki-button-focus-ring-color`          | Keyboard focus ring color             |
| `--ki-button-justify-content`           | Content placement (`center`)          |
| `--ki-button-text-align`                | Alignment of label lines (`center`)   |

The full matrix follows `--ki-button-{variant}-{tone}-{state}-{bg|border|fg}`
and `--ki-button-{size}-*`, plus the fidelity-pass effect tokens:
`--ki-button-{variant}-{state}-shadow` and the per-side bevel
`--ki-button-{variant}-rest-border-bottom` (raised variants only —
`quaternary` and `ghost` declare no bevel). Shadow parts: `::part(button)`
(internal native button, or link with `href`) and `::part(label)` (label
wrapper).

Toggle selection uses the `--ki-button-{variant}-selected-bg` and
`--ki-button-{variant}-selected-fg` pairs. The selected shape is controlled
by `--ki-button-toggle-selected-radius`. The fill stays fixed on hover.
The button's per-size icon token takes precedence over an explicit `size`
on a `ki-icon` in the `start` or `end` slot.

## Accessibility

- The default slot is the accessible name source — always provide visible
  label text; `ki-button` is not for icon-only compact controls.
- Native button semantics come from the internal native button: Space and
  Enter activation, form association and `event.submitter` behavior.
- With `href` the internal control is a native link named by the label:
  Enter follows it, Space does not, and it never acts on a form.
- `disabled` removes the button from keyboard reach and exposes the
  unavailable state; do not use it for pending/loading semantics.
- Every size keeps at least the minimum pointer target
  (`--ki-button-{size}-min-target`).
