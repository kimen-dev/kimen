# Loading a project card

Keep a named, busy section in the layout while the request is pending. Start with the skeleton hidden and give the section the same minimum block size as the expected content.

```html
<section id="project" aria-label="Loading project" aria-busy="true" style="min-block-size:6rem">
  <ki-skeleton hidden shape="rect" block-size="6rem"></ki-skeleton>
</section>
```

```js
async function showProject(region, loadProject) {
  const placeholder = region.querySelector('ki-skeleton');
  const reveal = setTimeout(() => {
    placeholder.hidden = false;
  }, 300);

  try {
    const project = await loadProject();
    region.replaceChildren(document.createTextNode(project.name));
  } finally {
    clearTimeout(reveal);
    placeholder.remove();
    region.setAttribute('aria-busy', 'false');
    region.setAttribute('aria-label', 'Project');
  }
}
```

Call `showProject` with the section and your data-fetching function. Handle request errors in the same region so the person waiting receives the outcome.
