# ki-list

A vertical list of static entries, links, settings controls, or selectable options. Use a direct `ki-list-item` child for each row.

## Examples

The list accepts only `ki-list-item` children; other children are
unsupported. Each item's default slot is the primary text line:

```html
<ki-list>
  <ki-list-item>Ada Lovelace</ki-list-item>
  <ki-list-item>Grace Hopper</ki-list-item>
  <ki-list-item>Margaret Hamilton</ki-list-item>
</ki-list>
```

Full item composition — `start` for leading media, `secondary` for
supporting text (its presence selects the multi-line min-height token) and
`end` for trailing media, meta text or a slotted control:

```html
<ki-list>
  <ki-list-item>
    <img slot="start" src="/avatars/ada.png" alt="" />
    Ada Lovelace
    <span slot="secondary">Analytical engine programs</span>
    <ki-badge slot="end" tone="success">Active</ki-badge>
  </ki-list-item>
  <ki-list-item>
    <img slot="start" src="/avatars/grace.png" alt="" />
    Grace Hopper
    <span slot="secondary">Compilers and COBOL</span>
    <span slot="end">1906–1992</span>
  </ki-list-item>
</ki-list>
```

## Interactive rows

```html
<ki-list label="Settings">
  <ki-list-item href="/settings/account">
    Account
    <span slot="secondary">Name, email, password</span>
  </ki-list-item>
</ki-list>
```

```html
<ki-list label="Reviewers" selection="multiple" name="reviewers" required>
  <ki-list-item value="ana" selected>Ana Garcia</ki-list-item>
  <ki-list-item value="luis">Luis Perez</ki-list-item>
</ki-list>
```

```html
<ki-list label="Notifications">
  <ki-list-item>
    Email digest
    <span slot="secondary">Every Monday</span>
    <ki-switch slot="end" checked></ki-switch>
  </ki-list-item>
</ki-list>
```

Give each interactive list a `label`. Set `selection="single"` for one
choice or `selection="multiple"` for independent choices. Set `selected` on
initial rows. The list's `ki-change` event carries `event.detail.value`, a
string or `null` in single mode and an array in multiple mode. Assign the
JavaScript `value` property to update selection silently.

Set `name` to submit the selection. Multiple selections submit one entry per
selected enabled row, in row order. Set `required` to require a choice. Form
reset restores the initial selection.

## Customization

| Token                           | Controls                              |
| ------------------------------- | ------------------------------------- |
| `--ki-list-gap`                 | Gap between items                     |
| `--ki-list-item-divider-color`  | Between-item divider color            |
| `--ki-list-item-min-height`     | Single-line item minimum height       |
| `--ki-list-item-primary-fg`     | Primary text color                    |
| `--ki-list-item-secondary-fg`   | Secondary text color                  |

Shadow parts: on the list, `::part(list)` (surface, padding, gap and
divider styling); on each item, `::part(item)` (row surface),
`::part(start)`, `::part(content)` (text column) and `::part(end)`.

Use `--ki-list-item-hover-bg` and `--ki-list-item-hover-fg` for hover,
`--ki-list-item-selected-bg` and `--ki-list-item-selected-fg` for selection,
and `--ki-list-item-interactive-radius` for interactive corners.
`::part(indicator)` exposes the decorative chevron, checkbox or radio.

## Accessibility

Navigation rows are native links. A named selection list exposes a listbox
with one tab stop. Arrow keys, Home, End and type-ahead move focus. Space or
Enter toggles the focused option. A row accepts one interaction: its link,
its option, or a control in the `end` slot. Development builds warn about
conflicting interactions. The row's primary text names an unlabeled trailing
control.
