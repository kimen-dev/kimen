# ki-list-item

A row in `ki-list` with primary text and optional leading media, supporting text, and trailing content. See the *ki-list* page for the container API and form examples.

## Examples

The default slot is the primary text line; `secondary`'s presence selects
the multi-line min-height token:

```html
<ki-list>
  <ki-list-item>
    <img slot="start" src="/avatars/ada.png" alt="" />
    Ada Lovelace
    <span slot="secondary">Analytical engine programs</span>
    <ki-badge slot="end" tone="success">Active</ki-badge>
  </ki-list-item>
</ki-list>
```

```html
<ki-list label="Settings">
  <ki-list-item href="/settings/account">
    Account
    <span slot="secondary">Name, email, password</span>
  </ki-list-item>
</ki-list>
```

```html
<ki-list label="Notifications">
  <ki-list-item>
    Email digest
    <span slot="secondary">Every Monday</span>
    <ki-switch slot="end" checked></ki-switch>
  </ki-list-item>
</ki-list>
```

## Customization

Row metrics and text colors are token decisions:
`--ki-list-item-min-height` (single-line), `--ki-list-item-divider-color`,
`--ki-list-item-primary-fg` and `--ki-list-item-secondary-fg`. Shadow
parts: `::part(item)` (row surface), `::part(start)`, `::part(content)`
(text column) and `::part(end)`.

Use `--ki-list-item-hover-bg` and `--ki-list-item-hover-fg` for hover,
`--ki-list-item-selected-bg` and `--ki-list-item-selected-fg` for selection,
and `--ki-list-item-interactive-radius` for interactive corners.
`::part(indicator)` exposes the decorative chevron, checkbox or radio.

## Accessibility

Keep the primary text in the default slot. Mark decorative media as hidden
from assistive technology or give decorative images empty alternative text.
Use `href` for a native link or place the row in a selection list to create an
option. To show a control, put one control in `end` on a default-mode row.
The primary text names the control when it has no authored name.
