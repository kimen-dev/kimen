# Spinner

Use `<ki-spinner>` for short waits inline. Choose `variant="dots"` for an
assistant that is thinking. Provide a localized activity label and set
`show-label` when the text should also be visible.

```html
<ki-spinner label="Saving changes…"></ki-spinner>
<ki-spinner variant="dots" label="Assistant is thinking" show-label></ki-spinner>
```
