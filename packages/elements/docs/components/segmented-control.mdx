# Changing a range in place

Use a segmented control when a choice immediately changes the view. Supply a
group label, two to five options and a distinct value for each option.

```html
<ki-segmented-control id="range" label="Chart range" value="week">
  <ki-segment value="day">Day</ki-segment>
  <ki-segment value="week">Week</ki-segment>
  <ki-segment value="month">Month</ki-segment>
</ki-segmented-control>
```

```js
const range = document.querySelector('#range');
range.addEventListener('ki-change', (event) => {
  updateChartRange(event.detail.value);
});
```

A group has one tab stop. Arrow keys move focus and select immediately.
Programmatic writes to `range.value` update the selection silently.

The default slot of each segment accepts its visible text. Put a decorative
icon in the `start` slot and use `aria-label` when the icon is the only content.
That name also appears in a tooltip. Use `full-width` for equal-width options
and `size="xs"`, `size="sm"` or `size="md"` for 28, 32 or 40px tracks.

The loader defines `ki-tooltip` when it appears in a segment’s shadow root. When using direct imports or
framework wrappers, register it separately for icon-only options.

Configure the track, item, and selected surfaces with their
`--ki-segmented-*-bg`, `--ki-segmented-*-bg-image` and backdrop-filter tokens.
Use the `track` and `button` parts for component-specific styling.
