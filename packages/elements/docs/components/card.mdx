# ki-card

Group related media, a heading, supporting text and actions on one surface.
Fill any subset of the regions. Use a native text heading in the `header`
slot to name a clickable card.

## Examples

All four regions — `media`, `header`, default (body) and `footer`:

```html
<ki-card>
  <img slot="media" src="/telemetry.png" alt="Orbit trajectory plot" />
  <h3 slot="header">Mission telemetry</h3>
  <p>Latest downlink completed at 14:02 UTC. All systems nominal.</p>
  <ki-button slot="footer" variant="secondary">View details</ki-button>
</ki-card>
```

Any subset of regions works — a text-only card is valid:

```html
<ki-card>
  <h3 slot="header">Storage almost full</h3>
  <p>You are using 92% of your plan. Consider archiving old projects.</p>
</ki-card>
```

Place separate actions in the `footer` slot.

```html
<ki-card>
  <h3 slot="header">Invite your team</h3>
  <p>Collaborators can review specs and approve merges.</p>
  <ki-button slot="footer" variant="primary">Invite</ki-button>
  <ki-button slot="footer" variant="ghost">Later</ki-button>
</ki-card>
```

## Variants and primary activation

`default` uses the theme's card. The `elevated`, `filled` and `outlined`
variants select a raised, tinted or bordered treatment.

```html
<ki-card variant="outlined" href="/incidents/42">
  <h3 slot="header">Search index rebuild</h3>
  <p>Scheduled for midnight.</p>
  <ki-button slot="footer" variant="secondary" type="button">Bookmark</ki-button>
</ki-card>

<ki-card variant="filled" interactive>
  <h3 slot="header">Preview monthly report</h3>
  <p>Review the new report before publishing it.</p>
</ki-card>
```

The first card follows its title link. Listen for `ki-activate` on the second
to handle the primary action. A nonblank `href` takes precedence when both
options are present.

## Customization

| Token                    | Controls                                |
| ------------------------ | --------------------------------------- |
| `--ki-card-bg`           | Card surface background                 |
| `--ki-card-radius`       | Card corner radius                      |
| `--ki-card-elevation`    | Card shadow (elevation ramp)            |
| `--ki-card-border-color` | Card border color                       |
| `--ki-card-gap`          | Gap between regions                     |

Per-region padding is available through
`--ki-card-{media|header|body|footer}-padding`. Shadow parts:
`::part(card)` (surface), `::part(media)`, `::part(header)`,
`::part(body)` and `::part(footer)` (region wrappers). Customize the primary
control with `::part(trigger)`. The variant colour pairs use
`--ki-card-{elevated|filled|outlined}-{bg|fg}`.

## Accessibility

- The author supplies the heading level. A clickable card exposes one
  primary link or button named by that heading, with a focus ring around
  the whole surface.
- Supporting text remains selectable. Secondary controls get their own
  focus stops and keep their own behavior.
- Give slotted media a meaningful `alt`, or an empty `alt=""` when decorative.
