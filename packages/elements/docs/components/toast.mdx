# ki-toast

A short, transient message about something the person just did, shown
without blocking the page. It leaves on its own after its time, which stops
while the person points at the toaster, works inside it or is away from the
page; a toast with an action, or reporting an error, waits for the person.

**When to use** — confirm an action that happened elsewhere on screen
("Changes saved", "Link copied"), report a background result ("Export
ready"), or offer a quick undo. Raise it into a `ki-toaster`.

**When NOT to use** — anything the person must read or act on to continue
(`ki-dialog`), form validation (the field's error text), or a lasting
condition of the page (`ki-alert`, which stays inline).

## Examples

```html
<ki-toaster>
  <ki-toast tone="success" heading="Changes saved">Workspace settings are up to date.</ki-toast>
</ki-toaster>
```

- `duration` (ms, default 5000) changes the time; `0` keeps the toast until
  it is dismissed. A `danger` toast or one with an action never leaves on its
  own.
- The `action` slot takes one ghost `ki-button size="sm"`; its click runs,
  then the toast leaves.
- `ki-dismiss` reports `detail.reason`: `"timeout"`, `"button"`, `"escape"`
  or `"action"`.
- `dismissible="false"` drops the dismiss button.

## Customization

| Token                              | Controls                                   |
| ---------------------------------- | ------------------------------------------ |
| `--ki-toast-bg` / `--ki-toast-fg`  | Surface fill and heading ink               |
| `--ki-toast-bg-image`              | Image over the fill (`none` by default)    |
| `--ki-toast-backdrop-filter`       | Backdrop filter (`none` by default)        |
| `--ki-toast-border`                | Hairline edge                              |
| `--ki-toast-shadow`                | Elevation                                  |
| `--ki-toast-{tone}-icon`           | Icon ink, per tone                         |
| `--ki-toast-heading-font-family`   | Heading typeface                           |
| `--ki-toast-width`                 | Widest a toast gets                        |

Shadow parts: `::part(toast)`, `::part(icon)`, `::part(heading)`,
`::part(message)`, `::part(action)` and `::part(dismiss)`.

## Accessibility

- `danger` exposes `role="alert"`; every other tone `role="status"`. No toast
  moves focus when it appears.
- Only the heading and the message are announced; the icon, the action and
  the dismiss button stay outside the live region.
- The time stops while the pointer rests on the toaster or focus is inside it
  (WCAG 2.2.1); Escape dismisses a focused toast and returns focus to where it
  was.
- `dismiss-label` is the only built-in word: localize it whenever the
  document language is not English.
