# Kimen component workshop

**Kimen Elements** is the Web Components foundation of Kimen's
multi-protocol GenUI system: **29** standards-first `<ki-*>` elements with
generated machine contracts and token-driven theming in any host. The GenUI
layer on top of it is implemented too — the neutral catalog
(`@kimen/catalog`) validates agent-emitted UI specs and renders them through
a fail-closed guarded renderer, and protocol adapters connect A2UI
(`@kimen/adapter-a2ui`) and MCP Apps (`@kimen/adapter-mcp-apps`) hosts to
that same guarded path.

This Storybook is the **component workshop**: every published component with
its props as live controls, its docs generated from the component contract
(the TypeScript types + JSDoc are the single source of truth), and an
accessibility panel wired to axe-core.

## How to read a component page

- **Playground** — every prop exposed as a control; slots shown as text.
- **Named stories** — one story per API axis (variants, tones, sizes…), so
  each design decision is visible in isolation.
- **Docs tab** — autogenerated from the manifest: props, events, slots,
  parts and CSS custom properties. If something is undocumented there, that
  is a build failure, not a docs gap.

## Theming in the toolbar

The **Scheme** toolbar switches light / dark / auto — it drives the same
`data-ki-color-scheme` attribute a consuming page would use. The workshop
also loads `@kimen/tokens/css/base` — the same page contract any consumer
loads — so the canvas (surface, text color, body font) follows the scheme
with you. The visual language you see is the MarsUI fidelity pass: motion,
glass, per-side bevel and elevation token families are part of the shipped
theme contract, not decoration bolted onto components. See
*Docs → Tokens & theming* for the full model.

## Where things live

  added during project-integrity hardening.

## For agents

Kimen treats machine legibility as a deliverable: components produce
when-to-use / when-NOT-to-use metadata, a generated manifest and `llms.txt`,
and the neutral catalog enforces a Zod-validated schema of what agents may
emit at the GenUI boundary — specs that fail validation never reach the DOM.
An API a capable agent cannot wire correctly from its description alone is a
defect — file it as one.
