# Kimen

This extension adds two agent skills and the `kimen` MCP server:

- `kimen-components`: pages and apps built with Kimen's `ki-*` web components
  and `--ki-*` design tokens.
- `kimen-genui`: agent-generated UI, where a JSON UI spec is validated and
  rendered by Kimen's guarded renderer.

Never guess a component, attribute, slot, event or token name. Read it from
the `kimen_list_components` and `kimen_describe_component` tools, or from
<https://kimen.dev/llms.txt> and `https://kimen.dev/llms/<tag>.md`.
