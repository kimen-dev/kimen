# Implementation plan

1. Establish the selection, accessibility, layout and A2UI contracts.
2. Scaffold the component with the discovery generator. Write browser tests
   for the scenario IDs and unit tests for form data, bounds and translation.
3. Add form association, direct option coordination and shared field messages.
   Use native checkbox interactions and a fieldset with a legend. Add the
   theme aliases, examples and galleries.
4. Translate multiple-choice A2UI nodes into the catalog-backed composition.
   Regenerate public surfaces and declare the additive API.
5. Run the local non-browser checks. The integrator runs browser verification,
   dispatches the Linux snapshots and re-syncs the design-system card.
