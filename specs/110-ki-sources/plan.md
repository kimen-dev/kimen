# Implementation plan: Sources

1. Lint and commit this contract. Scaffold each published tag against spec 110
   and commit the unit and browser tests before the implementation.
2. Use a native disclosure and ordered list. Resolve source definitions and
   first-reference order within each tree, including changes to streamed
   markup. Validate URLs before creating links.
3. Keep citation previews anchored, dismissible and keyboard-accessible. Paint
   using paired component colors, with the same semantic aliases in both
   themes where possible.
4. Complete the galleries, stories and documentation. Generate public
   surfaces, declare the API addition and run the available gates. The
   integrator runs the three-browser matrix and generates CI baselines.
