# Implementation plan

- Contracts and tests first. Exercise the load and refusal branches, source changes, figure semantics, keyboard traversal, accessibility and theme behavior through the built element. Use node tests for the pure URL policy and adapter translation.
- Scaffold through the component generator. Use a shadow figure, native image and caption, semantic token aliases and a fallback symbol. Keep the frame independent of loading and failure for explicit ratios.
- Reuse the scheme check from the catalog while keeping host-origin enforcement at the guarded render boundary. Opt the element into the generated catalog and map A2UI Image to it.
- Regenerate the public surfaces and declare the minor API addition. Run the available build, node, token and integrity checks. The integrator runs the real-browser suites and generates CI visual baselines.
