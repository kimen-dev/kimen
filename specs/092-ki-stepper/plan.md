# Stepper implementation plan

The stepper owns native ordered-list semantics and renders one list item per
direct step. Each source label remains slotted. The compact disclosure controls
the same list, so keyboard focus and step identity are tied to one set of links.

Use existing semantic color, type, density and sizing tokens. Use the shipped
Icon component for decorative completed and error marks. The discovery registry
generates the catalog entries, framework wrappers and public API snapshots.

Use the browser suites for keyboard, accessibility, direction, the theme
matrix and input preference checks. Verify the token aliases and contrast with
the token package checks. The integrator captures Linux visual baselines.
