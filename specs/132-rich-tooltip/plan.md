# Implementation plan

1. Extend the shipped tooltip and popover with opt-in contracts.
2. Write browser acceptance cases and unit coverage for rich tooltip text.
3. Bind rich tooltip text to a same-tree trigger description, reuse anchored
   placement and dismissal, and opt rich toggletips into dialog focus behavior.
4. Share semantic-backed rich visual tokens. Extend the existing galleries,
   docs and stories and regenerate the catalog, wrappers and public API.
5. Run the local quality gates and hand the browser and visual matrix to the
   integrator.
