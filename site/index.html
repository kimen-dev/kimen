Capability status

  • Schema-constrained guarded renderer: untrusted UI specs render only through the neutral catalog, fail-closed
  • Changed-core mutation quality gate in hardening
  • A2UI protocol adapter: declarative A2UI messages render through the guarded renderer
  • MCP Apps adapter: Kimen surfaces reach MCP Apps hosts as self-contained ui:// resources rendered through the guarded renderer
  • AG-UI and json-render protocol adapters planned
  • Neutral runtime component catalog with schema-validated UI specs at the GenUI boundary
  • Machine-readable Web Components foundation with token-driven theming

Deterministic quality

Done means gates exit 0.

Claims stay attached to executable evidence and the exact surface they describe.

real-browser

Current and previous engines

Chromium on every implementation change; Chromium, Firefox and WebKit before release.

axe-core

Accessibility is a gate

WCAG 2.2 AA and EN 301 549, plus keyboard and APG walkthroughs where automation stops.

single-digit KB

Budgets per component

Lazy custom elements, direct imports and no runtime dependency without a measured reason.

tokens-only

No hardcoded component visuals

Stylelint enforces the closed primitive → theme → semantic → component chain.

RTL

Direction-agnostic by construction

Logical properties make writing direction part of the baseline rather than a later variant.

mutation

Tests that test the tests

Changed-core mutation feedback runs daily; the ordinary PR loop stays focused and fast.
