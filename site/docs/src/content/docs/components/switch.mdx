A token-styled switch for binary settings whose change takes effect
immediately — always with a slotted label.

### Settings row

Set `display: block` in a block layout or stretch the switch in a grid.
The optional `end` slot holds a value at the inline end, outside the
switch's native label. Help and error messages appear below the row.

<Demo
  layout="block"
  code={`<ki-switch style="display: block" checked help-text="Get account updates by email.">
  Email notifications<span slot="end">On</span>
</ki-switch>`}
/>

Use `--ki-switch-label-font-size` and `--ki-switch-label-line-height`
to style the medium label. Insert `sm-`, `lg-`, or `xl-` after
`--ki-switch-` to target another size.

### Listening for changes

The composed `change` event fires at the host; read `checked` from the
target:

```ts
import type { KiSwitch } from '@kimen/elements/ki-switch';

const kiSwitch = document.querySelector('ki-switch');

kiSwitch?.addEventListener('change', (event) => {
  console.log((event.target as KiSwitch).checked);
});
```

## Accessibility

The default slot is the accessible-name source — unlabeled usage is invalid.
The thumb travel follows the writing direction in RTL, and the transition is
gated behind `prefers-reduced-motion`. For selections collected for later
form submission use [ki-checkbox](/docs/components/checkbox/); for
mutually exclusive choices use
[ki-radio-group](/docs/components/radio-group/).
