### Listening for changes

The composed `change` event fires at the host; read `checked` from the
target:

```ts
import type { KiSwitch } from '@kimen/elements/ki-switch';

const kiSwitch = document.querySelector('ki-switch');

kiSwitch?.addEventListener('change', (event) => {
  console.log((event.target as KiSwitch).checked);
});
```

## Accessibility

The default slot is the accessible-name source — unlabeled usage is invalid.
The thumb travel follows the writing direction in RTL, and the transition is
gated behind `prefers-reduced-motion`. For selections collected for later
form submission use [ki-checkbox](/docs/components/checkbox/); for
mutually exclusive choices use
[ki-radio-group](/docs/components/radio-group/).
