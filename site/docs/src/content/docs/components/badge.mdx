tone color only reinforces the text, it never replaces it.

## Accessibility

The badge has no live region: feedback that must be announced is
[ki-alert](/kimen/docs/components/alert/)'s job. Never ship an empty badge —
the slotted label carries the meaning, so color alone is never the carrier
(WCAG 1.4.1). For a state dot with no text of its own, use
[ki-status](/kimen/docs/components/status/).
