One selectable tab inside a [ki-tabs](/kimen/docs/components/tabs/) view
switcher. It labels the peer content view sharing its `value`, with optional
`start` and `end` slot media — never standalone.

  layout="block"

  <ki-tab-panel value="security">Security and sign-in preferences</ki-tab-panel>
</ki-tabs>`}
/>

## Accessibility

Selection is owned by the parent group: set `ki-tabs`' `value` instead of
authoring `selected`. A `disabled` tab stays visible but cannot be selected
by any modality.
