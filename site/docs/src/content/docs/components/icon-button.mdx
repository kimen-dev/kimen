A token-styled, icon-only action button with native button semantics and a
**mandatory accessible name** (`label`).

<Demo
  code={`<ki-icon-button label="Close">
  <ki-icon name="x"></ki-icon>
</ki-icon-button>`}
/>

## Examples

### Variants and tones

Use filled `primary` for the main action and outlined `secondary` (the default)
for supporting actions. Use `quaternary` for neutral icon actions and `ghost`
for accent icon actions. Use `outline` for a transparent outline at rest
and a filled selected state in toggle mode. The `tone` prop carries intent
for momentary actions in the primary, secondary, quaternary and ghost variants.

<Demo
  code={`<ki-icon-button variant="primary" label="Add item"><ki-icon name="plus"></ki-icon></ki-icon-button>
<ki-icon-button variant="secondary" label="Add item"><ki-icon name="plus"></ki-icon></ki-icon-button>
<ki-icon-button variant="quaternary" label="Add item"><ki-icon name="plus"></ki-icon></ki-icon-button>
<ki-icon-button variant="ghost" label="Add item"><ki-icon name="plus"></ki-icon></ki-icon-button>
<ki-icon-button variant="primary" tone="danger" label="Delete item"><ki-icon name="trash-2"></ki-icon></ki-icon-button>`}
/>

`tertiary` is deprecated. Use `secondary` for new icon buttons. Existing
`tertiary` buttons share the `secondary` appearance in onmars and keep
their legacy appearance in Material 3. Development builds warn when
the deprecated variant is used.

### Toggle mode

Add `toggle` to let an icon button stay pressed after activation. Set
`selected` to start pressed. Use the `selected` slot for a decorative icon
to display while pressed. With the default inline SVG alone, an outline
whose path inherits its fill becomes filled with `currentColor`.

<Demo
  code={`<ki-icon-button variant="outline" toggle label="Bookmark">
  <svg viewBox="0 0 24 24" fill="none" aria-hidden="true">
    <path d="M6 3h12v18l-6-4-6 4z" stroke="currentColor" stroke-width="2" />
  </svg>
  <svg slot="selected" viewBox="0 0 24 24" fill="currentColor" aria-hidden="true">
    <path d="M6 3h12v18l-6-4-6 4z" />
  </svg>
</ki-icon-button>`}
/>

The accessible name stays "Bookmark" in both states. User activation emits
a bubbling `ki-change` with `{ selected }`. Programmatic updates to
`selected` are silent.

Enabled outline actions use `--ki-icon-button-outline-hover-bg`,
`--ki-icon-button-outline-hover-fg` and `--ki-icon-button-outline-hover-border` on hover.
Unselected filled and quiet toggles use `--ki-icon-button-toggle-unselected-hover-overlay`.
A selected toggle keeps its fill on hover. Use `--ki-icon-button-outline-selected-border`
to set the selected outline edge.

The `--ki-icon-button-{size}-icon-size` token sizes a directly slotted
`ki-icon` glyph in either icon slot, including an icon with an explicit `size`.

### With a tooltip

Pair with [ki-tooltip](/docs/components/tooltip/) for sighted
discoverability — the tooltip's `label` becomes the accessible
*description*, complementing (never replacing) the icon button's own
`label`:

<Demo
  code={`<ki-tooltip label="Closes the dialog">
  <ki-icon-button label="Close">
    <ki-icon name="x"></ki-icon>
  </ki-icon-button>
</ki-tooltip>`}
/>

### Open a dialog

Pair `command="show-modal"` with the ID of a [ki-dialog](/docs/components/dialog/)
in the same document or shadow root. The `label` names the action and focus
returns to the icon button when the dialog closes.

<Demo
  code={`<ki-icon-button label="Project details" commandfor="icon-project-details" command="show-modal">
  <ki-icon name="info"></ki-icon>
</ki-icon-button>
<ki-dialog id="icon-project-details" heading="Project details">
  <p>This project is private.</p>
  <ki-button slot="footer" commandfor="icon-project-details" command="close">Done</ki-button>
</ki-dialog>`}
/>

## Accessibility

`label` is mandatory — there is no visible text to fall back on — and the
slotted icon should carry `aria-hidden="true"`. Whenever a visible label
fits, use [ki-button](/docs/components/button/) instead.
`ki-icon-button` is not form-associated: form submit/reset belongs to
`ki-button`, whose visible label communicates the consequence.
