A tiny, non-interactive status dot that marks the state of a nearby item —
presence on an avatar, health of a service list entry, connection state in a
toolbar.

  code={`<ki-status tone="success" label="Online"></ki-status>

### Ring

`ring` adds a surface-colored ring so the dot stays legible when overlaid on
media such as an avatar:

## Accessibility

Label it (`label`) or pair it with adjacent visible text — color is never
the only carrier of the meaning (WCAG 1.4.1); an unlabeled dot without
adjacent text is an authoring mistake. The dot never renders text (that pill
is [ki-badge](/docs/components/badge/)) and has no live region
(messages that need announcement are
[ki-alert](/docs/components/alert/)).
