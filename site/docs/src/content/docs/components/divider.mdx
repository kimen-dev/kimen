## Examples

### Vertical

`orientation="vertical"` separates side-by-side content; the divider takes
its size from your layout:

<Demo
  code={`<div style="display: flex; align-items: center; gap: 0.75rem; block-size: 2rem;">
  <span>Edit</span>
  <ki-divider orientation="vertical"></ki-divider>
  <span>Duplicate</span>
  <ki-divider orientation="vertical"></ki-divider>
  <span>Archive</span>
</div>`}
/>

## Accessibility

The divider is deliberately decorative: it contributes no role, name or
announcement. For semantic thematic breaks in running prose, use native
`<hr>`, which carries those semantics. Between list items, separation is a
[ki-list](/kimen/docs/components/list/) theme-token decision, not a divider.
