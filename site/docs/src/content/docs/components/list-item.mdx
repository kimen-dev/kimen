## Accessibility

Keep the primary text in the default slot. Mark decorative media as hidden
from assistive technology or give decorative images empty alternative text.
Use `href` for a native link or place the row in a selection list to create an
option. To show a control, put one control in `end` on a default-mode row.
The primary text names the control when it has no authored name.

Use `--ki-list-item-hover-bg` and `--ki-list-item-hover-fg` for hover,
`--ki-list-item-selected-bg` and `--ki-list-item-selected-fg` for selection,
and `--ki-list-item-interactive-radius` for interactive corners.
`::part(indicator)` exposes the decorative chevron, checkbox or radio.
