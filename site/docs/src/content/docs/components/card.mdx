Group related media, a heading, supporting text and actions on one surface.
Fill any subset of the regions.

<Demo
  layout="block"
  code={`<ki-card>
  <h3 slot="header">Weekly report</h3>
  Traffic is up 12% week over week; conversion held steady.
  <ki-button slot="footer" variant="secondary" type="button">View details</ki-button>
</ki-card>`}
/>

## Examples

### Regions

`media`, `header`, the default body and `footer` are independent slots:

<Demo
  layout="block"
  code={`<ki-card>
  <h3 slot="header">Just the header and body</h3>
  Cards render only the regions you fill; empty regions collapse.
</ki-card>`}
/>

### Secondary controls

Place separate controls in the body or footer.

<Demo
  layout="block"
  code={`<ki-card>
  Ready to publish this draft?
  <ki-button slot="footer" variant="primary" type="button">Publish</ki-button>
  <ki-button slot="footer" variant="ghost" type="button">Discard</ki-button>
</ki-card>`}
/>

### Surface variants

`default` uses the theme's card. Use `elevated` for a raised surface,
`filled` for a tint or `outlined` for a visible border.

<Demo
  layout="block"
  code={`<ki-card variant="elevated"><h3 slot="header">Elevated</h3>A raised surface.</ki-card>
<ki-card variant="filled"><h3 slot="header">Filled</h3>A tinted surface.</ki-card>
<ki-card variant="outlined"><h3 slot="header">Outlined</h3>A bordered surface.</ki-card>`}
/>

### Clickable cards

Set `href` to link to another view. Set `interactive` for a button that emits
`ki-activate` once. Each needs a single text heading in the `header` slot.
When both options are present, the card follows `href`.

<Demo
  layout="block"
  code={`<ki-card variant="outlined" href="#examples">
  <h3 slot="header">Search index rebuild</h3>
  <p>Scheduled for midnight.</p>
  <ki-button slot="footer" variant="secondary" type="button">Bookmark</ki-button>
</ki-card>
<ki-card interactive variant="filled">
  <h3 slot="header">Preview monthly report</h3>
  <p>Review the new report before publishing it.</p>
</ki-card>`}
/>

## Accessibility

Supply a heading in the `header` slot at the level required by the page
outline. In a clickable card, the title is the name of the primary link or
button. Tab reaches it once, with a focus ring around the card, and reaches
each secondary control separately. Supporting text remains selectable. Use
the title link for native link gestures such as opening a new tab.
