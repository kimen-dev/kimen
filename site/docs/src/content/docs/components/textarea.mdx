descriptions, messages, delivery notes.

## Examples

### In a form

<Demo
  layout="block"

  <ki-button variant="primary">Send</ki-button>
</form>`}
/>

### Initial value

Initial text is declared through the `value` attribute; element text content
is ignored:

<Demo
  layout="block"
  code={`<ki-textarea label="Bio" value="Design systems, gates, and coffee."></ki-textarea>`}
/>

## Accessibility

The `label` prop is the accessible name — mandatory, and `placeholder` is
never a substitute. Enter inserts a line break and never submits the
enclosing form — the inverse of [ki-input](/kimen/docs/components/input/).
For single-line values use `ki-input`; rich or formatted editing is out of
scope.
