## Interactive rows

```html
<ki-list label="Settings">
  <ki-list-item href="/settings/account">
    Account
    <span slot="secondary">Name, email, password</span>
  </ki-list-item>
</ki-list>
```

Give each interactive list a `label`. Set `selection="single"` for one
choice or `selection="multiple"` for independent choices. Set `selected` on
initial rows. The list's `ki-change` event carries `event.detail.value`, a
string or `null` in single mode and an array in multiple mode. Assign the
JavaScript `value` property to update selection silently.

Set `name` to submit the selection. Multiple selections submit one entry per
selected enabled row, in row order. Set `required` to require a choice. Form
reset restores the initial selection.

## Accessibility

Navigation rows are native links. A named selection list exposes a listbox
with one tab stop. Arrow keys, Home, End and type-ahead move focus. Space or
Enter toggles the focused option. A row accepts one interaction: its link,
its option, or a control in the `end` slot. Development builds warn about
conflicting interactions. The row's primary text names an unlabeled trailing
control.
