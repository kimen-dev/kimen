## Examples

### Dialog commands

`ki-button` and `ki-icon-button` can invoke a dialog by ID within the same
document or shadow root. Once the elements are registered, the markup handles
opening and closing. `show-modal` opens the dialog, `close` dismisses it, and
`request-close` first gives the dialog a chance to cancel the request. Attach
your application logic to the confirmation button to perform the deletion.

### The close contract

Use a footer command or call `close()` to dismiss programmatically.
The `ki-close` event reports the reason in `detail.reason`. The
`close` command and an accepted `request-close` report `command`. A call
to `close()` reports `method`, Escape reports `escape`, and opt-in
backdrop dismissal (`close-on-backdrop`) reports `backdrop`.
Centered dismissals and programmatic closes report after focus returns.

```ts
dialog.addEventListener('ki-close', (event) => {
  console.log(event.detail.reason); // 'command' | 'method' | 'escape' | 'backdrop'
});
```

### Fullscreen

Use `fullscreen="compact"` to fill windows narrower than 600 CSS pixels.
Choose `always` to fill the window at any width. The default, `never`,
uses the centered layout. The header stays visible while the body scrolls.

<Demo
  layout="block"
  code={`<ki-button commandfor="event-dialog" command="show-modal">Add event</ki-button>
<ki-dialog id="event-dialog" heading="New event" fullscreen="compact"
    confirm-label="Save" close-label="Discard and close">
  <ki-input label="Title" value="Design review"></ki-input>
  <ki-input label="Date" value="24 Nov 2026"></ki-input>
</ki-dialog>`}
/>

`confirm-label` puts a ghost button in the fullscreen header and a primary
button in the centered footer. Handle `ki-confirm` to validate and save,
then call `close()` when the task is complete. The footer slot remains
available for additional actions.

In fullscreen, Escape and the header close button emit a cancelable
`ki-close` before dismissal. Call `preventDefault()` to keep the dialog
open, for example when the draft has unsaved changes. The button reports
`method`. Bind `open` when you need to track whether dismissal took effect.

```ts
const dialog = document.querySelector('ki-dialog#event-dialog');

dialog?.addEventListener('ki-close', (event) => {
  if (event.cancelable && hasUnsavedChanges()) event.preventDefault();
});
dialog?.addEventListener('ki-confirm', async () => {
  if (await saveEvent()) await dialog.close();
});
```

## Accessibility

Always provide a `heading` — APG modal dialogs require an accessible name.
In destructive confirmations put `autofocus` on the least destructive
action. An opener with `command="show-modal"` exposes the dialog popup and
its expanded state, then regains focus after close. When using `show()`, call
it from the control that should receive focus again. Non-blocking feedback belongs to
[ki-alert](/docs/components/alert/); supplementary hints to
[ki-tooltip](/docs/components/tooltip/).
